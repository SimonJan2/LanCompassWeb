# מלאי

רישום הנכסים — מלאי hardware ו־software עם serials, מקושר לאתרים.

## שדות

| שדה | הערות |
|---|---|
| **Kind** | `hardware` או `software` |
| **Category** | קיבוץ טקסט חופשי (שרת, מתג, רישיון…) |
| **Vendor / Model** | מה זה |
| **Purpose / Version** | למה זה / מה זה מריץ |
| **EOL on** | תאריך end-of-life |
| **Support status** | למשל `under support`, `EOL`, `best effort` |
| **Serial number** | מפתח מעקב ראשי — ניתן לחיפוש מהפלטה |
| **Site** | איפה זה חי |
| **Notes** | טקסט חופשי |

## מקורות

נכסים בדרך כלל מגיעים דרך [ייבוא ה־workbook](/he/docs/import/) (משפחות
הגיליונות של assets/inventory) ושומרים `import_batch_id` מקורי בחזרה
לאצווה שלהם — אבל שורות יכולות גם להיווצר ולהתערך ביד.

## עבודה עם הרשימה

סידור, נעיצה, תג, צבע שורה, עריכות inline, היסטוריה. מספרי serial וזוגות
vendor/model מוצגים בתוצאות [פלטת הפקודות](/he/docs/search-and-shortcuts/)
תחת "Inventory".

## קריאת העמוד

- **סטריפ סטטיסטיקות** — חלוקת hardware/software, EOL שעבר, EOL בתוך 90
  יום, serial חסר, בלי אתר. כל כרטיס הוא קיצור לחיצה-לסינון.
- **טאבי Kind** — All / Hardware / Software מחלקים את הטבלה.
- **עמודים** — הרשימה מציגה 100 נכסים בכל פעם. החיפוש, טאבי Kind, כרטיסי
  הסטטיסטיקות והמיון לפי עמודה פועלים על כל המלאי; הדפדוף שליד החיפוש עובר
  מעמוד לעמוד.
- **Group by** — כיווץ שורות תחת כותרות קטגוריה, אתר או vendor (השורות של
  העמוד הנוכחי, ושורות כל קבוצה נשארות יחד).
- **Columns** — בורר נראות לתצוגות צפופה מול מינימלית.
- **Saved views** — מובנים כמו "EOL < 90 days" ו"Routers w/o site".

לנתונים בצורת-גיליון שאינם נכס (רשימות שרתים, רשימות אנשי קשר…), ראו
[רשימות מותאמות](/he/docs/lists/).
