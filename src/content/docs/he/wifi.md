# רשתות WiFi

רשתות WiFi הן **SSID-ים לוגיים** — כל שורה ממדלת רשת אלחוטית אחת כפי שאתם
מתכוונים שהיא תהיה: לאיזה אתר היא שייכת, לאיזה VLAN היא קשורה, ואילו
נקודות גישה משדרות אותה.

זהו תיעוד של מצב-רצוי, לא סנכרון בקר — סריקות ו־[SNMP](/he/docs/snmp/) ממשיכים
להתבונן על המציאות; העמוד הזה הוא המקום לתעד מה *אמור* לשדר.

## הרשימה

WiFi מציג כל SSID עם התדר שלו, מצב האבטחה, ה־VLAN הקשור, האתר
ומספר המכשירים המשדרים. SSID-ים הם **ייחודיים לכל אתר** — אותו שם באתר
אחר הוא שורה אחרת.

- **Band** — `2.4`, `5`, `6` GHz או `dual`.
- **Security** — `open`, `wpa2`, `wpa3` או `enterprise` (802.1X).
- **Hidden** — דגל SSID לא-משדר; שורות מוסתרות מקבלות תג.
- **Enabled** — כבו כדי לשמור את הרשומה תוך סימון כהוצאה משירות; שורות
  מכובות מוצגות מעומעמות.
- **Bound VLAN** — ה־[VLAN](/he/docs/vlans/) שאליו לקוחות נוחתים. זו התשובה
  ל״איזו רשת משנה ה־SSID הזה מחלק״ — העמודה שרוב הדוחות בעצם מבקשים.

## מכשירים משדרים

לחצו על מספר ה־AP בשורה (או פתחו את השורה עם `Enter`) כדי לנהל את
**סט השידור** — ה[מכשירים](/he/docs/devices/) שנושאים את ה־SSID הזה. חברים
חייבים להיות מכשירים עם `family=wifi`: הגדירו את ה־family של AP ברשומת
המכשיר קודם, ואז הוא מופיע בבורר. שמירה מחליפה את כל הסט בכתיבה אחת —
ה־diff מחושב בצד השרת, אז החלפה בטוחה באמצע audit.

## סקיצת API

```
GET    /api/v1/wifi-networks?q=&site_id=&vlan_id=&band=&security=
       &enabled=&hidden=          # כל facet של עמודה הוא פרמטר
POST   /api/v1/wifi-networks      # site+ssid ייחודי — 409 בכפילות
GET    /api/v1/wifi-networks/{id}
PATCH  /api/v1/wifi-networks/{id}
DELETE /api/v1/wifi-networks/{id}
PUT    /api/v1/wifi-networks/{id}/devices   # {device_ids:[…]} — הסט כולו;
                                           # חברים לא-wifi הם 422
```

שורות מבוקרות ב־audit — כל שינוי ב־SSID נוחת ב
[יומן השינויים](/he/docs/changelog/), וגיבויים נושאים את הרשת + טבלאות
ה־join של השידור.
