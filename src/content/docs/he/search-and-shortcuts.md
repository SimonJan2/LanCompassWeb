# חיפוש וקיצורים

⁦LanCompass⁩ הוא מקלדת-קודם. כל קיצור רשום בשכבת-העל שנפתחת עם `?` או
**כפתור המקלדת** ליד החיפוש בכותרת.

## פלטת הפקודות

פתחו עם **⌘K / Ctrl+K**, מקש `/`, או כפתור החיפוש בכותרת. הקלידו כדי
לחפש בכל ה־IPAM:

- כתובות IP, רשתות משנה, אתרים, VRF-ים, VLAN-ים
- קווים, תעודות, נכסי מלאי, שירותים
- מדריכי **Docs** תואמים (הם מופיעים כקבוצת "Docs")

הדביקו כתובת IP חשופה והפלטה מציעה תוצאת **Jump** שנוחתת ישירות על
הקידומת הבעלים עם הכתובת מודגשת — מעדיפה את הבעלים המתועד של הכתובת,
ואז את הקידומת העמוקה ביותר שמכילה אותה.

בלי שאילתה, הפלטה מציגה את חמשת היעדים האחרונים שלכם.

### חיפוש בעברית

הפלטה, תיבת החיפוש של כל רשימה וחיפוש המדריכים מנרמלים עברית באותו אופן
בשני הצדדים, כך שאפשר להקליד כמו שהמקלדת מקלידה:

- אותיות סופיות שוות לצורתן הרגילה — `שלום` מוצא את `שלומי`;
- ניקוד וטעמים לא נלקחים בחשבון — `שלום` מוצא את `שָׁלוֹם`;
- הגרשיים והגרש שווים למירכאות ולגרש של המקלדת — `דוא"ל` מוצא את `דוא״ל`,
  ו־`ב'` מוצא את `ב׳`;
- המקף העברי שווה למקף רגיל — `באר-שבע` מוצא את `באר־שבע`, וגם להפך;
- אותיות לטיניות גדולות וקטנות נחשבות זהות.

חיפוש שאין בו עברית (כתובת, MAC, שם לטיני) מותאם כפי שהוקלד. כשהממשק
בעברית, רשימות שממוינות לפי שם (אתרים, מכשירים, ארונות, VLAN-ים וקבוצות
הפלטה) ממוינות בסדר עברי — ספרות, אחריהן עברית בלי תלות בניקוד, ואחריהן
לטינית; באנגלית הסדר נשאר כמו שהיה. חיפוש המדריכים מוצא גם את מילות המפתח
של כל פרק בשפה שלכם.

## chord-ים של גישה

לחצו `g`, ואז אחד מ:

| מקשים | יעד |
|---|---|
| `g d` | דשבורד |
| `g v` | ביקורת |
| `g p` | רשתות משנה |
| `g s` | סריקות |
| `g i` | תיבת דואר של Discovery |
| `g c` | יומן שינויים |
| `g r` | רacks |
| `g e` | מכשירים |
| `g m` | ניטור |
| `g t` | טופולוגיה |
| `g h` | Docs (הסקשן הזה) |

## ניווט בטבלאות

| מקש | פעולה |
|---|---|
| `j` / `↓` | שורה הבאה |
| `k` / `↑` | שורה קודמת |
| `Enter` | פתיחת השורה הממוקדת |
| `Home` / `End` | שורה ראשונה / אחרונה |
| `Alt+↑` / `Alt+↓` | הזזת השורה הממוקדת (רשימות ניתנות-לסידור) |

## רשת רשתות המשנה

בתוך [מטריקס רשתות המשנה](/he/docs/subnets/) של קידומת:

| מקש / מחווה | פעולה |
|---|---|
| `← ↑ ↓ →` | תנועה בין כתובות |
| `Enter` | פתיחת הכתובת |
| גרירה | בחירת טווח כתובות |
| `Esc` | ניקוי בחירת הטווח |

## כללי היקף

קיצורי מקש-בודד אף פעם לא יורים בזמן שאתם מקלידים בשדה או כשדיאלוג/תפריט
פתוח — כך ש`j`, `k`, `/` ו`?` בטוחים לשימוש כטקסט. **⌘K / Ctrl+K** הוא
היוצא מהכלל: הוא מחליף את הפלטה מכל מקום, כולל בתוך דיאלוגים.

## במקלדת עברית

כל הקיצורים עובדים גם כשפריסת המקלדת עברית: מקש של אות מפעיל את אותו קיצור
בלי קשר לאות שהוא מקליד — **Ctrl+K** הוא המקש שמקליד `ל`, `g` `e` הם
המקשים שמקלידים `ע` `ק`, ו־`j` / `k` הם `ח` / `ל`. מקש הלוכסן פותח את
הפלטה גם כשבמקלדת עברית הוא מקליד `.`. שכבת-העל של הקיצורים (`?`) מציגה
את האות העברית מתחת לכל קיצור. בפריסה לטינית האות נקראת כפי שהוקלדה (Z
במקלדת גרמנית נשאר Z).
