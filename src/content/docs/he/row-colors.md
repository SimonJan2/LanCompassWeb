# צבעי שורות וכללי צבע

שתי דרכים לצבוע שורות רשימה כך שהדברים החשובים בולטים — **ידני**, מוגדר לכל
שורה על ידי כל מי שיכול לכתוב נתונים, ו**מבוסס-כלל**, מנוהל על ידי אדמינים
ומחושב בצד השרת.

## צבעי שורות ידניים

לכל רשימה — אתרים, VRF-ים, VLAN-ים, רשתות משנה, קווים, תעודות, נכסים,
שירותים, תגיות ורשימת הכתובות — יש פעולת **Set color** לכל שורה. בחרו
גוון והשורה מוצגת איתו לכולם. נקו אותו באותה דרך.

כפתור ה**legend** על רשימה מסביר את הגוונים בשימוש כרגע.

## כללי צבע (אדמין)

**Settings → Color Rules** מגדיר תנאים שצובעים שורות אוטומטית:

| חלק | דוגמה |
|---|---|
| **Entity** | `Certificate` |
| **Field** | `expires_on` |
| **Operator** | `within_days` |
| **Value** | `7` |
| **Color** | red |

→ "תעודות שפוקעות תוך 7 ימים מוצגות באדום." Operators: `eq`, `neq`,
`contains`, `lt`, `gt`, `within_days`; שדות מוקלדים (טקסט, תאריך, bool,
מספר, enum) כך שעורך הכללים מציע רק operators הגיוניים.

לכללים יש **מיקום** — הם חלים בסדר, והכלל הראשון שמתאים מנצח. צבע שורה
ידני דורס כללים לשורה הזו (הגוון האפקטיבי חשוף כ`display_color`).

## כיסוי

צבעים מאוחסנים ב־Postgres, מחושבים בצד השרת, ומכוסים ב[גיבוי](/he/docs/settings/)
ו[יומן שינויים](/he/docs/changelog/) — שחזור מחזיר גם את הצבעים שלכם.
