# תעודות

עקבו אחר פקיעת תעודות בכל המערך כדי ששום דבר לא יפוג בשקט.

## שדות

| שדה | הערות |
|---|---|
| **Platform** | איפה התעודה חיה (LB, שרת web, appliance…) |
| **Target** | נקודת הקצה המוגנת |
| **Server name** | ה־host שעליו התעודה מותקנת |
| **Cert name** | שם תעודה ידידותי |
| **Expires on** | התאריך המנוטר — מניע את הספירה לאחור |
| **Device** | הקופסה שעליה התעודה יושבת — קישור לדף המכשיר |
| **Serial** | מחרוזת serial גולמית |
| **Notes** | טקסט חופשי |

## מעקב פקיעה

- שורות מציגות **תג פקיעה** עם ספירה לאחור חיה.
- ה**דשבורד** מציג תעודות שפוקעות תוך **30 יום** (`certs_expiring_30d`) כדי
  שחידושים יהיו גלויים ברגע הכניסה.
- שלבו עם [כלל צבע](/he/docs/row-colors/) כמו *"expires_on בעוד 7 ימים → אדום"*
  כדי שחידושים דחופים יהיו בלתי-ניתנים להחמצה.
- קשרו את התעודה ל**מכשיר** ודף המכשיר יציג אותה תחת *Related* עם אותו chip
  של ספירה; פריט הפקיעה במרכז הסקירה מזכיר את הקופסה. מחיקת מכשיר עושה את
  התעודה יתומה (קישור מתנקה, שורה נשמרת) — אף פעם לא מוחקת אותה.

## עבודה עם הרשימה

**מסנן המכשירים** מעל הטבלה מצמצם את הרשימה לתעודות על קופסה אחת (זמין גם
מהקישורים בעמודת המכשיר).

יכולות רשימה מלאות: סידור, נעיצה, תג, צבע שורה, עריכות inline, היסטוריה
לשורה. תעודות ניתנות לחיפוש מפלטת הפקודות ומכוסות בגיבוי + יומן שינויים
כמו כל ישות אחרת.

## תעודות שהתגלו

כשה[גילוי](/he/docs/discovery/) פועל, כל נקודת קצת ⁦TLS⁩ שבדיקה מגיעה אליה
נרשמת עם טביעת האצבע של התעודה, הפקיעה והמקור כשורה במפתח
**(host, port, fingerprint)** — כך שאותה תעודה על אותו מאזין היא שורה
אחת שמתרעננת במקום ערימת כפילויות. השורות האלה נושאות
`source = discovery` ונספרות באותם משטחי פקיעה: מדד ה־30 יום בדשבורד,
פריט הפקיעה במרכז הסקירה, קריאות ה־digest בדוח, וממצאי *שירותים
חשופים* (תעודות self-signed, מתפוגעות או פגות מרימות את כללי ה־baseline
המתאימים). מחיקת שורת גילוי תשוחזר בריצה הבאה שרואה את התעודה; התעודה
עצמה נעלמת רק כשהיא מפסיקה להיות מוצגת.

**תעודה שערכתם שייכת לכם.** שינוי של שדה כלשהו בתעודה שהתגלתה — שם השרת,
ההערות, תאריך הפקיעה שידוע לכם — הופך אותה ל־`source = manual`: אף ריצה
מאוחרת יותר לא מחזירה את הערכים האלה. ריצה עדיין מוצאת את השורה לפי המארח
והפורט שלה ולעולם לא מוסיפה שורה שנייה לצידה; כשהמאזין מציג תעודה אחרת,
הריצה רושמת פריט סטייה מסוג `tls_changed` עם טביעת האצבע והפקיעה החדשות,
במקום לכתוב מחדש את השורה שלכם.
