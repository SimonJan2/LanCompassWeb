# שירותים

קטלוג השירותים — מה הרשת *משרתת*, לא רק ממה היא בנויה.

## שדות

| שדה | הערות |
|---|---|
| **Name** | שם השירות (למשל `CRM`, `File share`) |
| **Beneficiary** | מי צורך אותו — צוות, מחלקה, לקוח |
| **Site / Site code** | איפה הוא עוגן |
| **Device** | הקופסה שמריצה אותו — קישור לדף המכשיר |
| **Doc path** | קישור ל־runbook-ים או תיעוד חיצוני |
| **Test info** | איך לוודא שהשירות בריא |
| **Notes** | טקסט חופשי |

## למה לעקוב אחר שירותים ב־IPAM?

כשרשת משנה משתנה או סריקה מוצאת סטייה, השאלה היא תמיד "למי זה משנה?".
קישור שירותים לאתרים נותן את רדיוס הפגיעה: הקווים, התעודות והנכסים של אותו
אתר במרחק קפיצה אחת.

קישור ל־**מכשיר** עונה על "איזו קופסה מריצה אותו" — דף המכשיר מציג את
השירותים שלו תחת *Related*, ומחיקת המכשיר עושה את שורת הקטלוג יתומה
(הקישור מתנקה) במקום למחוק אותה.

## עבודה עם הרשימה

**מסנן המכשירים** מעל הטבלה מצמצם את הרשימה לשירותים על קופסה אחת (זמין גם
מהקישורים בעמודת המכשיר).

אותן יכולות כמו בכל רשימה — סידור, נעיצה, תג, צבע שורה, עריכות inline,
היסטוריה. ניתן לחיפוש מהפלטה תחת "Services", ובדרך כלל מאוכלס דרך
[ייבוא ה־workbook](/he/docs/import/).
