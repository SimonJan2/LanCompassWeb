# רשימות מותאמות

טבלאות מוגדרות-משתמש לנתונים שלא נכנסים לישות קבועה — רשימות שרתים, רשימות
אנשי קשר, מטריצות סביבה, כל דבר שהיה חי בגיליון workbook ואיבד את הצורה שלו
בייבוא.

רשימה היא הבעלים של **העמודות** שלה (מסודרות, מוקלדות) ושל **השורות** שלה
(נתוני JSON מקושרים לעמודה), כך ש״שרתים בייצור״ נשאר טבלה עם עמודת
`Guest OS` במקום להתמוסס לתוך הערות של נכסים.

## סוגי עמודות

| סוג | התנהגות |
|---|---|
| **text** | טקסט חופשי, חיפוש מודע-עברית |
| **ip** | נרשם חי מול `ip_addresses` — נקודת סטטוס, last-seen, קליק → מגירת כתובת. IP-ים לא-נרשמים מוצגים מעומעמים/מקווקווים, מה שמציף סטייה בין הרשימה ל־IPAM. תאים מופרדי-פסיקים נרשמים לכל כתובת. |
| **date** | מוצג דרך תג הפקיעה — עיצוב באיחור / ימים-נותרים |
| **select** | אפשרויות קבועות מוצגות כ־chips צבעוניים; משמש ל־facets |
| **number** | מספרי, מיון מיושר-ימינה |
| **url** | קישור חיצוני לחיץ |
| **owner** | אדם/אחריות — מוצג כמו chips של select |

עמודות מקושרות לפי מיקום (`c0`, `c1`, …) — **שינוי שם או תווית של עמודה
אף פעם לא נוגע בנתונים המאוחסנים**. הסרת עמודה מסתירה אותה; ערכי התאים
נשמרים.

## עבודה עם רשימה

כל עמוד `/lists/{slug}` הוא טבלה מלאה: מיון, עריכה inline לפי סוג תא,
סידור בגרירה, נעיצה, צבעי שורות, חיפוש עם קיפול-עברית, תצוגות שמורות
וייצוא CSV — אותן מכניקות כמו בכל עמוד אחר.

- **נעצו** שורות חשובות בראש; **צבעו** שורות לסטטוס.
- **Add Row** יוצר שורה ריקה; התאים מתמלאים בעריכה.
- **בחרו שורות** עם תיבות הסימון לפעולות bulk — נעיצה, ביטול נעיצה,
  הגדרה או ניקוי צבע שורה, מחיקה.
- **Settings** (אייקון גלגל שיניים) משנה את שם הרשימה, עורך עמודות
  (תווית מחדש, שינוי סוג, גרירה לסידור, הוספה, הסרה) ובוחר את
  **עמודת המפתח**.

## עמודת המפתח וייבוא-מחדש

עמודת המפתח היא זהות המיזוג (למשל `Name`). כשאותו גיליון מיובא שוב:

- תאים משתנים מתעדכנים במקום; שורות חדשות נוצרות.
- שורות שנעדרות מהמקור **נשמרות** ומדווחות כ־*missing from source* —
  אף פעם לא נמחקות בשקט.
- שורות שערכתם ביד מוגנות: אם הגיליון חולק, הערך הידני מנצח והשורה
  מדווחת כהתנגשות.
- נעיצות, צבעים, סידור ושורות שנוספו ידנית תמיד שורדים.

## מאיפה רשימות מגיעות

- **Import file** על `/lists` — זרקו כל `.xlsx` או `.csv`, בחרו את הגיליון,
  תנו שם לרשימה, בחרו מפתח מיזוג, dry-run, commit. ייצואי CSV מפוענחים
  כ־UTF-8 או ANSI-Hebrew (cp1255) אוטומטית.
- [אשף הייבוא](/he/docs/import/) מציע **Import as → Custom list** לכל גיליון;
  גיליונות ממשפחה לא-מוכרת מציעים אותו כברירת מחדל. עם *also import to
  IPAM* מופעל, גיליון שרתים מאכיל את שניהם — הרשימה שומרת את צורתה
  האנושית בזמן שה־IP-ים שלה נוחתים ב־`ip_addresses`.
- או צרו רשימה ריקה ובנו אותה ביד.

שמות רשימות וערכי מפתח שורות מופיעים ב[חיפוש הגלובלי](/he/docs/search-and-shortcuts/).
