# תגיות

תוויות צבעוניות שאפשר להצמיד ל**אתרים, VRF-ים, קידומות וכתובות** —
ל־"prod", "legacy", "customer-X" או כל טקסונומיה שאתם מנהלים.

## שדות

| שדה | הערות |
|---|---|
| **Name** | שם תצוגה |
| **Slug** | מזהה נגזר אוטומטית |
| **Color** | צבע ה־chip, נבחר מפלטה |
| **Description** | ניתן לעריכה inline ישירות בטבלה |

## הצמדת תגיות

- מ**בורר התגיות** של שורה (אייקון התג בפעולות השורה) — מחליף תגיות על
  האובייקט.
- מ**דיאלוג עריכה** — שדה התגים בטופסי יצירה/עריכה.
- ב**כמות** — בחרו שורות ברשימת ישויות או טווח במטריקס של רשת המשנה והחילו
  תג על כולן.

chips של תגיות מוצגים על שורות בכל מקום שהאובייקט מופיע — רשימות,
מגירות, תוצאות חיפוש.

## עבודה עם הרשימה

- **גררו לסידור** — הסידור הזה חי ומשותף (אין בקרות מיון בעמוד הזה).
- **נעצו** תגית כדי לשמור אותה בראש.
- **צבעי שורות** עובדים גם כאן — שורת תגית יכולה בעצמה להיות צבועה.
- כל שינוי ב[יומן השינויים](/he/docs/changelog/); מחיקת תגית מסירה נקי את
  ההקצאות שלה בכל מקום.

מחיקת אובייקט מתויג מסירה גם היא רק את ההקצאות — התגית עצמה שורדת.
