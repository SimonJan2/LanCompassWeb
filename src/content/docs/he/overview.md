# סקירה כללית

⁦LanCompass⁩ הוא מנהל כתובות IP (IPAM) מתארח-עצמית עם סורק LAN מובנה. הוא שומר
את הרשת **המתועדת** ואת הרשת **האמיתית** שלכם מסונכרנות: אתם ממדלים את
מרחב הכתובות, הסורק מאמת אותו, וסטייה מופיעה כנתון במקום כהפתעה.

## מודל הנתונים

הכל תלוי על היררכיה אחת:

**אתר ← VRF ← קידומת ← כתובת IP**

- **אתרים** הם מיקומים פיזיים או לוגיים (סניפים, מרכזי נתונים, קומות).
- **מופעי VRF** הם טבלאות ניתוב נפרדות בתוך אתר — טווחי CIDR חופפים מותרים *בין*
  מופעי VRF שונים אבל נדחים *בתוך* אחד.
- **קידומות** הן רשתות משנה. קידומת מסוג „מכולה” מחזיקה רשתות משנה-ילדות
  ופטורה מבדיקות חפיפה.
- **כתובות IP** חיות בתוך קידומות ונושאות סטטוס, תפקיד, כתובת MAC, שם מארח
  ונתוני גילוי.

מסביב לליבה יושבים **רשתות VLAN**, **טווחי IP** (בלוקים של
DHCP, מאגר ושמורים, שמוחרגים מהקצאה), **תגיות** ו**צבעי שורות**.

## סיור בממשק

סרגל הצד מקובץ כמו הנתונים:

| קבוצה | מה בפנים |
|---|---|
| *(ראש)* | **דשבורד** — הדשבורדים שלכם, עם [גלריית הדשבורדים](/he/docs/dashboard-gallery/) |
| **IPAM** | **אתרים**, **VRF**, **VLAN**, **רשתות משנה**, **בקשות** (בקשות IP), **היררכיה** (העץ), **טופולוגיה** — המפה החיה, הקנבסים וסטודיו העיצוב |
| **מלאי** | **קווים**, **תעודות**, **מלאי** (נכסים), **רשימות**, **ארונות**, **מכשירים**, **ספרייה** (מה שמקורות הספרייה אומרים על כל מחשב), **WiFi**, **שירותים** |
| **תפעול** | **סקירה**, **ניטור**, **תקלות**, **בקרת גישה (NAC)**, **תיבת גילויים**, **סריקות**, **ייבוא**, **דוחות**, **יומן שינויים** |
| **מערכת** | **תגיות**, **מסמכים** (המדריך הזה), **הגדרות** |

בכותרת יש את כפתור **חיפוש** (⌘K / Ctrl+K), את כפתור **קיצורי המקלדת**
ואת **סריקה מהירה**. בתחתית סרגל הצד מוצג המשתמש המחובר, והסרגל מתכווץ
לשורת סמלים.

## תיעוד מול תיעוד API

מדור התיעוד הזה הוא מדריך המשתמש. תיעוד ה־API שמכונה קוראת (Swagger)
חי על שירות ה־API ב־`http://<host>:8001/docs` — אותו נתיב, פורט שונה.
ה־UI מדבר איתו בשבילכם; פתחו אותו ישירות לסקריפטים.

## לאן להמשיך

- התקנה חדשה? התחילו עם [חשבונות ותפקידים](/he/docs/accounts-and-roles/).
- ממדלים רשת? [אתרים](/he/docs/sites/) → [VRF-ים](/he/docs/vrfs/) →
  [רשתות משנה](/he/docs/subnets/) → [כתובות IP](/he/docs/addresses/).
- יש לכם גיליון? קפצו ל[ייבוא](/he/docs/import/).
- רוצים שהרשת תבדוק את עצמה? [סריקות](/he/docs/scans/) ו
  [תיבת הגילויים](/he/docs/discovery/).
