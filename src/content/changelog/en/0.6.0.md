### Upgrading from 0.5.0

- **Extract the new bundle into `incoming/`**, never over the install, and
  run its `upgrade.sh` from your install directory (`INSTALL.md` §6). A
  signed bundle prints its key's fingerprint: compare it with
  `INSTALL.md` §1.
- **The backup the upgrade takes.** `upgrade.sh` runs `python -m app.cli
  preflight` and `python -m app.cli backup` on the running 0.5.0 before it
  changes anything; that file in `backups/` is your rollback file. It then
  loads the 0.6.0 images (the old ones stay loaded), keeps your Compose
  file as `docker-compose.yml.pre-0.6.0`, changes only the
  `LANCOMPASS_VERSION=` line of `.env`, and starts 0.6.0, which runs the
  32 migrations.
- **The drill.** On 0.6.0 it takes a second backup and runs a restore
  drill on it. When another restore drill is already running — a fresh
  install's first scheduled drill, a minute or two after the install — it
  prints "Another restore drill is running — trying again in 10 s." and
  waits, up to five minutes (`LANCOMPASS_DRILL_RETRY_SECONDS`, default
  10, 30 tries). A drill that fails stops the upgrade at once.
- **The rollback** steps are printed on any failure and at the end of a
  successful upgrade, for later: the schema back to 0.5.0's revision with
  the new image, the old Compose file and version line, `up -d
  --no-build`, then the rollback file in Settings → Restore.
- **What an upgrade keeps.** Your `.env` stays as it is: a 0.5.0 install
  that took no scheduled backups keeps taking none until you turn them on
  (Settings → Backup; fresh 0.6.0 installs back up nightly and keep 14).
  An install with no licence starts a 30-day evaluation at its first 0.6.0
  start and turns read-only after it; upload the licence in Settings →
  License.

### Known issues

What a pilot can still meet on this release, each checked on it:

- **Roles from nested groups on a hardened Active Directory
  (B-AD-GROUPBASE, S2, partly fixed).** Group roles are read through
  `tokenGroups`; where the bind account may not read it, LanCompass falls
  back to the membership search under the user search base, which a
  narrowed base can hide a nested group from. Proved only on the lab's
  directory: check a nested administrator's first sign-in on your own.
- **Deliveries still run one by one inside the monitor sweep
  (B-OBS-SLOWCHAN and B-NOTIFYPATH's open row, S2, partly fixed).** A
  channel that never answers (a webhook to an unreachable address) can
  hold the sweep that confirms an outage. The rehearsal's alert step
  passed with one channel.
- **The wall's Availability gauge overlaps itself at 1920 × 1080 in
  comfortable density (S3).** The percentage, the "Off target" chip and
  the bar overlap on the Night Watch wall. Workaround: compact density
  lays it out cleanly.
- **The English A4 portrait report's Subnet capacity section cuts the site
  name (S3).** On a large estate every row's Site reads "Scale site…".
  Workaround: print the report on A4 landscape, which prints each name
  whole.
- **The Hebrew report prints the discovery drift section's kinds and
  states as raw tokens (S3)** (`os_changed`, `port_opened`,
  `acknowledged`), on paper and on the Reports page alike.
- **In the Hebrew docs, a code block's copy button covers the first
  letters of the command** (`docker compose down -v` reads "ker compose
  down -v" on screen). The copy button copies the whole command, and the
  printed page shows it whole.
- **For about a minute after an install, the dashboard says background
  work is not running**, until the scheduler's first tick; it clears by
  itself.
- **F1 — the docs, NetBox and workbook imports inflate each zip member
  whole, with no cap.** One person with `data:write` can make the API run
  out of memory with a small archive. Workaround: give `data:write`
  (contributors and administrators hold it) only to people you trust; the
  API restarts on its own. The fix is the first security fix after this
  release.
- **F4 — a direction-override character (U+202E) in a typed name** shows
  the name reordered on pages and in CSV exports. The design canvas and
  discovery already strip it; typed names keep it.
- **F8 — a viewer is offered controls the server refuses:** the docs
  editor by its URL, and Settings → Dashboards' *Apply starter kits* and
  *Import a pack…*. Each save is refused.
- **What is not guarded** — monitor probes that reach loopback or a
  metadata address (F2), SMTP and syslog hosts (F3) and the `server`
  header (F6) — is written down in `SECURITY.md`, which this bundle
  carries.
