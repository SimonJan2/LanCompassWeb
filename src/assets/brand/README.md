# Brand mark

- `compass-app-icon.svg` — copied unchanged from `LanCompass/frontend/src/app/icon.svg`
  (product `v0.5.0`). Source of the favicon, apple-touch icon, manifest icons and OG images.
- `compass.svg` — the same mark without the dark tile, for use on ink backgrounds.
  `src/components/CompassMark.astro` inlines it.

Rules: the wordmark is "LanCompass" (one word, capital L and C), set in the display
font beside the mark. Never mirror the compass in right-to-left layouts.
