# Brand mark

- `compass-app-icon.svg` — copied unchanged from `LanCompass/frontend/src/app/icon.svg`
  (product `v0.5.0`). Source of the favicon, apple-touch icon, manifest icons and OG images.
- `compass.svg` — the same mark without the dark tile. `src/components/CompassMark.astro`
  inlines it. On the site's light paper it is always drawn on its app-icon tile (`tile`),
  because the white north needle needs the dark ground; the mark itself never changes.

Rules: the wordmark is "LanCompass" (one word, capital L and C), set in IBM Plex Sans
beside the mark. Never mirror the compass in right-to-left layouts.
