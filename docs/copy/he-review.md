# Hebrew copy review

For the native Hebrew reviewer. Every Hebrew string on the site, with a literal English back-gloss (what the Hebrew says, not the English page) and a one-word note:

- **kept**: identical to W1.
- **new**: a string W1 did not have (new layout).
- **rewritten: voice** — re-authored in the register of [`he-voice.md`](he-voice.md); **glossary** — a term aligned with the product's own Hebrew interface (קידומת, פאנל פאץ׳, גילוי סביל, תור הסקירה); **address** — form of address fixed (verbal nouns on buttons, first-person neutral consent, no slash forms); **calque** — a translated turn of phrase removed; **length** — headline cut to 3–8 words.

Strings are grouped by file. `copy.*` keys live in `src/content/copy/he.ts`, `ui.*` keys in `src/i18n/he.json`, and the long-form pages in `src/content/pages/he/*.mdx`. Latin-only strings (product names, the integration list) are listed once at the end. Markup (`<bdi>`, `<code>`) is removed here for reading; it stays in the source.

What to look for: anything that sounds translated, any term an Israeli network engineer would not use, and any sentence a reader would stumble on. Mark the row and suggest the Hebrew; the facts must stay the same (claims list in the W1 brief).
